# my-first-site

## Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Conventions
- No frameworks or build tools
- One CSS file: `style.css`
- One JS file: `script.js`
- Entry point: `index.html`

## Key Decisions
- Keep it simple — no npm, no bundler, no dependencies
- All secrets in `.env` only (never hardcode, never commit)
